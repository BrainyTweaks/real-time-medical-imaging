# Real-Time Medical Imaging

> MathWorks Excellence in Innovation — Project 259  
> Real-Time Acceleration for Medical Image Processing

## Overview

This repository contains the development of a real-time medical image
processing and interpretation pipeline developed for the MathWorks
Excellence in Innovation Challenge, Project 259, in collaboration with
Analog Devices, Inc. (ADI).

The project investigates an end-to-end workflow for medical imaging,
with a focus on ultrasound/RF data processing, image reconstruction,
image enhancement, AI-based interpretation, GPU/CUDA acceleration,
and NVIDIA Holoscan deployment.

## Planned Pipeline

Raw / Simulated Sensor Data
→ Signal Processing
→ Image Reconstruction
→ Image Enhancement
→ AI Inference
→ GPU/CUDA Acceleration
→ NVIDIA Holoscan
→ Real-Time Output

## Project Status

**Phase 0 — Project Foundation & Onboarding**

The repository is being established before technical implementation begins.

## Objectives

The project aims to:

- investigate reconstruction of medical images from raw sensor/RF data
- develop and validate a MATLAB reference implementation
- evaluate image enhancement techniques
- investigate an AI-based medical image analysis task
- profile computational bottlenecks
- accelerate suitable processing stages using GPU/CUDA
- integrate the accelerated pipeline with NVIDIA Holoscan
- evaluate latency, throughput, image quality, and AI performance
- provide a reproducible end-to-end implementation

## Important Note

This project is an experimental engineering/research prototype.
It is not a clinically validated diagnostic system.

## Project Requirements

The project follows the requirements of MathWorks Excellence in Innovation
Project 259.
